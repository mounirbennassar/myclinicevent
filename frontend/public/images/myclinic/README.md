# Official My Clinic imagery

Downloaded from the user-provided main website, https://myclinic.com.sa/, for the My Clinic events platform.

- reception.webp — https://myclinic.com.sa/clinic/reception.webp

Facility photos illustrate My Clinic's environment, not footage from specific events. Event cards label them accordingly. Photography is locally hosted and served through Next.js Image with responsive sizing.

Brand reference: #003868 navy, #004d99 blue. The main website uses Tajawal for Arabic, Manrope for English body copy, and Poppins for English headings. Those fonts are applied to the events homepage and catalogue.
